   73: Music::NWC2MusicXML::Event - Internal representation of a single NWC musical event
   74: or score metadata record.
   75: 
   76: =head1 VERSION
   77: 
   78: 0.01
   79: 
   80: =head1 SYNOPSIS
   81: 
   82:     use Music::NWC2MusicXML::Event;
   83: 
   84:     # Musical event
   85:     my $note = Music::NWC2MusicXML::Event->new(

   90:             pitch      => 'C',
   91:             octave     => 4,
   92:             accidental => 0,
   93:         },
   94:     );
   95: 
   96:     # Unsupported / unknown object
   97:     my $unknown = Music::NWC2MusicXML::Event->new(

   99:         nwc_label => 'SomeFutureObject',
  100:         data      => { raw => '|SomeFutureObject|...' },
  101:     );
  102: 
  103: =head1 DESCRIPTION
  104: 
  105: C<Music::NWC2MusicXML::Event> is the internal representation of one NWC record.
  106: It covers both musical events (notes, rests, bars, dynamics, ...) and
  107: score/staff metadata (SongInfo, StaffProperties, ...).
  108: 
  109: Musical timing is represented using exact rational numbers stored as
  110: two-element arrayrefs C<[$numerator, $denominator]>.  Floating-point
  111: arithmetic is never used for musical durations; this avoids cumulative
  112: rounding errors when dividing a beat into complex tuplet groupings.
  113: 
  114: Unknown NWC object types are stored as C<UnsupportedEvent> records so
  115: that conversion can continue rather than aborting.
  116:
