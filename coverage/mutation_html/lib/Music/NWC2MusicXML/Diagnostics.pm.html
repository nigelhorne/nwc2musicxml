   67: 0.002.4

   69: =head1 SYNOPSIS
   70: 
   71:     use Music::NWC2MusicXML::Diagnostics;
   72: 
   73:     my $diag = Music::NWC2MusicXML::Diagnostics->new(
   74:         level        => 'verbose',

   83:         reason => 'No MusicXML equivalent',
   84:     );
   85: 
   86:     $diag->summary;
   87: 
   88: =head1 DESCRIPTION
   89: 
   90: Centralises all diagnostic output for the Music::NWC2MusicXML pipeline.  No
   91: module should print warnings or debug traces directly; instead each module
   92: receives a C<Diagnostics> instance and routes output through it.
   93: 
   94: Supports four severity levels: quiet, normal (default), verbose, debug.
   95: Warnings can be written to an optional file handle (C<--warnings FILE>).
   96: A summary count (processed / successful / warnings / failed) is maintained
   97: and can be printed at batch completion.
   98: 
   99: =cut
